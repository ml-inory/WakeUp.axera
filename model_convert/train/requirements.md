# 唤醒词模型训练需求（已对齐）

## 目标

让唤醒词 **“你好，爱芯”** 可被检测：唤醒词出现时 3 帧滑动和 > 阈值触发，
其他语音/噪声保持静默。替换现有逆向版模型，并完成
AX650（NPU3）/ AX620E（NPU2）预编译 AXMODEL 交付。

## 任务类型

唤醒词检测（KWS），帧级二分类（wake / non-wake），后处理为 3 帧滑动和阈值检测。

## 数据

- 来源：edge-tts 多音色合成（无 GPU、无真实录音，TTS 为务实路径）
- 正样本：“你好，爱芯” 及其发音变体（你好 爱芯 / 你好，Aixin / 你好爱芯 等）
- 负样本：其他常见短语（你好，小爱 / 你好，其他 / 打开空调 等）+ 噪声
- 增强：音量抖动、加噪、随机裁剪、轻微变速

## 模型

- 架构：WakeNet9 复刻（conv1 + LN + LIGLU×5 + 残差 + conv2 + L2norm + conv3 + log_softmax）
- 输入：log-fbank (1, 26, 64)，16kHz，32ms/32ms 帧
- 初始化：参考浮点权重（`ref_model/`，conv3 ×4 修正），全网络解冻微调

## 精度目标

| 指标 | 目标 |
|------|------|
| 正样本触发率（TTS 变体验证集） | ≥ 90%（3 帧滑窗和 > 0.615） |
| 负样本误触率 | ≤ 5% |
| 验收“你好，爱芯”音频 | 必须触发 |
| 验收“你好，其他”音频 | 必须静默 |
| ONNX vs PyTorch | cos ≥ 0.999 |
| AXMODEL 板端 | 与浮点触发行为一致（INT8） |

## 效率约束

- 保持输入 (1,26,64) 静态 ONNX、INT8 量化，AX650 每帧推理预算 ≤ 32ms（现 1.83ms）

- 训练产物：best_model.pt、training_log.json、validate.py、accuracy_report.json
- ONNX + 导出脚本；Pulsar2 编译 NPU3/NPU2 AXMODEL；替换 SDK 示例音频；
  更新 GitHub ml-inory/WakeUp.axera；HF 重新发布（用户确认后）

## 风险

- TTS 与真实麦克风录音域差异：板端用真实录音 sample 验证，若失败需用户提供更多真实录音
- few-shot 微调过拟合：验证集用未见过的 TTS 音色
- 负样本不足导致误触发：负样本文本尽量覆盖常见语音场景
