# 唤醒词训练调研报告

## 结论

复用现有 WakeNet9 复刻架构 + 逆向权重微调，不另选新架构。

## 理由

1. **交付链路已打通**：现有浮点复刻 → ONNX (1,26,64) → Pulsar2 INT8 →
   NPU3（AX650，板端实测 1.83ms/帧）/ NPU2（AX620E）编译、仿真、板端验证全流程已验证，
   换成新架构需重做整个编译/量化/板端链路。
2. **唤醒词声学相近**：参考权重（WakeNet9 预训练）与目标 “你好，爱芯” 同为
   “前缀 + 中文双音节”，声学特征接近，是 few-shot 微调的理想起点（分类器头/中间层
   只需小幅调整）。
3. **模型极小**（0.5MB INT8）：CPU 微调即可，无需 GPU。
4. **备选：esp-sr 官方自定义训练**（云端服务，2-3 周）：不开源训练管线、周期长、无法
   本地复现，已排除。

## 候选训练方案对比

| 方案 | 优点 | 缺点 |
|------|------|------|
| 全网络解冻微调（选此） | 能充分适配新唤醒词；数据量小时靠预训练权重兜底 | 需防过拟合 |
| 仅微调 conv3/分类头 | 最稳，不易崩 | 中间特征仍是旧词，新词适配能力弱 |
| 从头训练 | 无参考残留 | 数据不足（仅 TTS），极易过拟合/不触发 |

采用：**全网络解冻微调 + 小学习率 + 权重衰减**，用未见过的 TTS 音色做验证集。
